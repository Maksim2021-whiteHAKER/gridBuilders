# GridBuilders 🏗️

**Сетевые строители** — платформа для совместного 3D-строительства в реальном времени.

**GridBuilders** позволяет строить карты и модели вместе в реальном времени с любого устройства и экспортировать результат в Roblox Studio.

## 🎯 Какую проблему решает

В командной разработке Roblox-игр часто возникает ситуация: один разработчик на ПК, а другой — на телефоне. Мобильный Roblox Studio урезан, и полноценно строить карту вместе невозможно.

**Для кого:**
- 🛠 Разработчики Roblox-игр
- 🎨 3D-художники и дизайнеры уровней
- 👥 Команды без доступа к ПК для всех участников

## 🎮 Как использовать

1. **Создайте проект** — зарегистрируйтесь и создайте новую сцену
2. **Опубликуйте сцену** — поделитесь ссылкой для просмотра
3. **Стройте** — добавляйте объекты, перемещайте их, настраивайте материалы
4. **Совместный режим** - нажмите "👥🔗" чтобы включить синхронизацию в реальном времени с другими участниками
5. **Экспортируйте** — скачайте результат в .rbxmx для Roblox Studio или .GLB для других движков, либо .JSON для резервной копии

## 🔥 Возможности

- 🌐 **Кроссплатформенность:** работайте на ПК и сенсорных устройствах
  - *ПК* — полный функционал: моделинг, экспорт/импорт
  - *Сенсорные устройства* — передвижение/создание объектов, импорт моделей
- 👥 **Совместное строительство в реальном времени (beta):** 
  - *Синхронизация через Appwrite Realtime (~1 сек. задержки)* 
  - *Soft-delete + корзина для онлайн режима*
  - *Защита от перетирания локальных изменений*
- 📤 **Экспорт** в Roblox Studio (.rbxmx), .GLB, .JSON
- 📥 **Импорт** из форматов .JSON, .GLB, .OBJ
- 👀 **Понятный интерфейс** с сеткой (grid-based building)
- 🚧 [WIP] Presence - видеть курсоры других пользователей
- 🚧 [WIP] История версий сцены

## 👩‍💻 Технологический стек

- **Frontend:** React 19 + TypeScript + Three.js (React Three Fiber) + zustand
- **Backend:** Appwrite (Auth + Databases + Realtime)
- **Сборка:** Vite
- **Лицензия:** AGPL-3.0

## 📦 Установка

> ⚠️ **Внимание:** Проект находится в активной разработке. для запуска нужен аккаунт Appwrite (free tier OK)

```bash
# Клонирование репозитория
git clone https://github.com/Maksim2021-whiteHAKER/gridBuilders.git
cd gridBuilders

cp .env.example .env
# Заполните VITE_APPWRITE_PROJECT_ID, VITE_APPWRITE_ENDPOINT,
# VITE_APPWRITE_DATA_BASE_ID, VITE_APPWRITE_COLLECTION_ID

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

```
